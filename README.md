# Maths2 — version autonome

Application web de mathématiques en français : cours, exercices guidés, QCM, flashcards avec répétition espacée, référentiel et suivi local.

## Installer / publier
1. Télécharge et décompresse `Maths2.zip`.
2. Envoie **tout le contenu du dossier** à la racine de ton dépôt GitHub Pages (index.html, app.js, data.js, style.css, manifest.webmanifest et dossier icons).
3. Dans GitHub : Settings → Pages → déployer depuis `main` / `/ (root)`.
4. Ouvre l'URL GitHub Pages et fais Ctrl+F5.

Aucune compilation ni installation n'est nécessaire. La progression est enregistrée dans le navigateur de l'appareil avec localStorage ; elle n'est pas synchronisée entre appareils.

## Contenu
- 18 fiches de cours L1/L2/MP, avec définitions, propriétés, exercice, indice et correction.
- Mini-QCM dans chaque fiche.
- 24 flashcards avec notation du rappel et programmation des prochaines révisions.
- Référentiel filtrable et tableau de progression.
- Visualisations intégrées aux fiches : suites, limites, continuité, dérivation, intégrales, DL, injectivité, déterminant, Gram-Schmidt, Fourier, trigonométrie et valeurs propres.

Les animations sont dessinées sur canvas avec prise en charge de la densité de pixels de l'écran. Les notions et exercices restent à enrichir au fil du cursus.
